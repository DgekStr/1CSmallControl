📘 Кластер: как работать с базами

0. Быстрый порядок для новой базы

  1. Создать пустую БД в PostgreSQL (роль + база, пароль — из настроек кластера).
  2. «Кластер» → «Создать инфобазу»: имя, пользователь PostgreSQL и его пароль.
  3. Опубликовать: sudo 1c-republish-base <имя> <имя_БД>.
  4. Админка → Базы: добавить запись, указать URL публикации, выдать доступ клиентам.
  5. Загрузить данные (толстый клиент): Конфигуратор → «Администрирование» → «Загрузить информационную базу» → выбрать файл .dt.
  6. Применить эталонных пользователей: sudo /usr/local/bin/1c-apply-template-users <имя_БД>
  7. Вход по умолчанию: Бухгалтер / 000 (или dgek с паролем кластера). Пароль лучше сменить сразу после первого входа.

Если база импортируется из .dt, эталонных пользователей нужно применять после загрузки: 1С перезаписывает таблицу пользователей.

1. Создать базу

  1. Создайте роль и пустую БД в PostgreSQL: 
    sudo -u postgres psql -c "set password_encryption='md5'; create role usr_buh2 login createdb superuser password 'СЛОЖНЫЙ_ПАРОЛЬ'"
sudo -u postgres psql -c "create database buh2 owner usr_buh2"
  2. В разделе «Кластер» заполните форму «Создать инфобазу».
  3. Опубликуйте: sudo 1c-republish-base buh2 buh2
  4. Добавьте базу в портал (Админка → Базы) и выдайте доступ клиентам.

2. Перенести данные

  • Штатно — Конфигуратор → Администрирование → Восстановить из .dt.
  • Через pg_restore: только в пустую БД, затем обязательно: 
    sudo -u postgres psql -d buh2 -c "REASSIGN OWNED BY postgres TO usr_buh2"
sudo -u postgres psql -d buh2 -c "GRANT ALL ON SCHEMA public TO usr_buh2"
sudo -u postgres psql -d buh2 -c "ALTER DATABASE buh2 OWNER TO usr_buh2"
  • После импорта откройте базу. Ошибка «Не найдена лицензия» = повреждённая инфобаза: пересоздайте её на той же БД (п. 3).

3. Пересоздать инфобазу без потери данных

  1. Снимите сеансы: Статистика → «Отключить всех».
  2. Удалите инфобазу в «Кластере» (БД PostgreSQL остаётся).
  3. Создайте инфобазу с тем же именем, БД и пользователем.
  4. Опубликуйте: sudo 1c-republish-base имя имя

4. Удалить базу

  1. Снимите сеансы и удалите инфобазу.
  2. Удалите БД и роль: 
    sudo -u postgres psql -c "select pg_terminate_backend(pid) from pg_stat_activity where datname='buh2'"
sudo -u postgres psql -c "drop database buh2 with (force)"
sudo -u postgres psql -c "drop role usr_buh2"
  3. Удалите публикацию: sudo rm -rf /var/www/1c/buh2, перезагрузите Apache.
  4. В портале: Админка → Базы → удалить запись и доступы.

5. Права

  • Удаление и переименование инфобазы доступно только администратору кластера, добавленному в администраторы этой ИБ.
  • Добавить администратора ИБ можно только из консоли администрирования серверов 1С (Информационные базы → свойства → Администраторы).
  • rac не принимает логин пользователя базы, ibcmd не меняет регистрацию в кластере.

6. Песочницы

  • Копия из свежего дампа: 1c-sandbox create <база> <имя> <дамп>.
  • Скрипт создаёт роль, БД, инфобазу, публикацию и копирует пользователей 1С.
  • Одна копия на клиента, заменяется новой, продлевается и удаляется из админки.
