Гейты контроля (что нельзя пропускать)

G1 · после теста дома

  • Вход в dgek_db и открытие 2–3 форм
  • Отчёт (ОСВ) строится, данные на месте
  • 5 одновременных сеансов без ошибок лицензий
  • Бэкап создан и восстановлен на тестовую БД
  • Обновление конфигурации прогнано (или проверено, что не падает)

G2–G4 · переезд и кластер

  • G2: pvecm status — 4 узла, Quorate: Yes
  • G3: ВМ 213 запущена, /WEB/dgek_db/ = 200, портал жив
  • G4: лицензии видны, сеансы входят, ночной бэкап проходит
  • Старая ВМ выключена, конфликт IP .5 исключён

ИИ-агент в стеке работ

Что агент делает сам

  • Этапы 0, 3, 5, 6, 7 — команды Proxmox/SSH, восстановление, join, миграция, проверки
  • Сбор метрик: CPU, IOPS, время отклика форм, SMART
  • Прогон чек-листов и сравнение конфигураций до/после
  • Отчёт по каждому гейту (в чат; Mattermost — по команде)
  • Контроль бэкапов и тестовое восстановление

Где нужен человек

  • Установка Proxmox с ISO (консоль/IPMI)
  • Физический переезд, монтаж, кабели
  • Подключение ключей HASP (USB/сеть)
  • Разрешение на необратимые шаги: остановка боевой ВМ, вывод узлов
  • Согласование окна и приёмка результата
Правила работы агента: без отдельного разрешения не выполнять необратимые шаги (стирание дисков, вывод узлов из кластера, остановка боевой ВМ 213). Все команды логируются, после каждого этапа — короткий отчёт и контрольная точка у человека. При отказе на гейте — откат на предыдущее состояние (снапшот/дам).
