Сервер 1С — конфигурация, закупка и прирост скорости

Сравнение текущего сервера (файловые базы 1С через RDP) и целевой конфигурации после закупки и переезда на PostgreSQL + Proxmox.

Эталон (текущее состояние): сервер с 1С на файловых базах, доступ пользователей через RDP, 32 ГБ ОЗУ, Kingston SSD, HDD 1 ТБ под копии баз, NVMe M.2 под систему Windows Server 2019.

Откуда прирост (коротко)

  • Файловые → PostgreSQL: данные не «гоняются» по сети целым файлом, работают индексы и транзакции БД.
  • SATA → NVMe: чтение/запись случайных блоков в разы быстрее — критично для 1С.
  • 32 → 64 ГБ: вся «горячая» часть базы помещается в кэш, дисковых обращений меньше.
  • RDP → веб/тонкий клиент: нет оверхеда графического рабочего стола на каждого пользователя.
  • i7 → i9 (опц.): +2 ядра на параллельную работу пользователей.
