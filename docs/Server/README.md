## Железо нового сервера (актуально)

| Компонент | Значение |
|---|---|
| CPU | **AMD Ryzen 9 3900X** — 12 ядер / 24 потока, 3,8–4,6 ГГц |
| Плата | **MSI B450 Tomahawk Max** (AM4, 4×DDR4, 1×M.2, 6×SATA) |
| Память | 32 ГБ сейчас → **64 ГБ** (докупаем +32 ГБ) |
| Система | Patriot Burst 480 ГБ (SATA) → Proxmox |
| Базы 1С | **NVMe 1 ТБ** в M.2 (PostgreSQL) — докупаем |
| Горячий клон | **NVMe 1 ТБ** через адаптер GLOTRENDS PA19 в x16 — докупаем |
| Архив | HDD 1 ТБ (есть) |
| БП | 850 Вт (есть) |

Бюджет закупки: **≈ 32 000–43 000 ₽** (обязательный минимум), с видеокартой и кулером — до 49 000 ₽.

## Правила

- **Старые серверы не трогаем**: кластер pve/pve2/pve3 и ВМ 213 продолжают работать.
- Переключение 1С — только в согласованное окно и с возможностью отката.
- Бэкапы: NVMe-миррор → ежедневные дампы → HDD + сетевое хранилище 192.168.0.20.
