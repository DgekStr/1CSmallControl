1C-AI-Control — варианты логотипа

v3.0.0 · знаки: A — монограмма «1C» + искра ИИ · B — база + пульс · C — щит + база · D — чип «AI»; E/F — логотипы с надписью

Знаки (иконки приложения)

A. Монограмма «1C» + искра
Прямое указание на 1С, зелёная искра — ИИ. Лучше всего читается в маленьком размере.
рекомендуюиконкааватар
B. База + пульс
База данных и линия пульса: «база жива, под контролем». Метрика мониторинга, без буквы 1С.
мониторинглендинг
C. Щит + база
Защита и сохранность: копии, доступы, контроль. Хорошо для блока «безопасность».
безопасностьB2B
D. Чип «AI»
Акцент на ИИ-составляющей. Абстрактно, без привязки к 1С — хорошо для ИИ-модуля.
ИИ-модульфича

Логотипы с названием

E. Горизонтальный (основной)
Для сайта, презентаций, писем: знак + название + подзаголовок «копии · мониторинг · ИИ-проверки баз 1С».
основнойшапка сайтадокументы
F. Вертикальный
Для аватара, обложки, визитки, экрана входа в панель.
обложкаэкран входа
Палитра: глубокий синий #0F1524 · фиолетовый #7C5CFF–#5B3FD1 · зелёный #2FBF71 · светло-серый #F6F8FC.

Шрифт: Segoe UI / Inter, полужирный, отрицательный трекинг — строго, без засечек.

Файлы: SVG (масштабируется без потерь) + PNG-превью. Для иконок приложения нужны размеры 512/192/64 px — сгенерируем из SVG.

Юридическая заметка

«1С» — товарный знак фирмы «1С». В самом названии продукта лучше не использовать логотип 1С и не писать «1С» как часть бренда без партнёрства; в подзаголовке «для 1С» — допустимо. Вариант A использует только текст «1C» как обозначение совместимости, без логотипа 1С.
