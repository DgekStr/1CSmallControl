Развёртывание

Система ставится параллельно, отдельными виртуальными машинами:

ВМЧто на ней
ВМ сервисапанель 1C-AI-Control + контроллер (без 1С)
ВМ 1С-сервера (клон)1С:Предприятие + агент; RAS 1545 доступен только ВМ сервиса

Миграции с 2.1.2 нет — старая версия остаётся рабочей на своём сервере и не затрагивается.

Кратко о продукте

Коммерческий сервис управления парком 1С:

  1. Панель на отдельном сервере (без sudo, без локальных скриптов).
  2. Агент на сервере 1С — привилегированные операции через HTTP+токен.
  3. ИИ-модуль — проверки данных в песочнице (никогда в живой базе).
  4. Аренда: тарифы по количеству баз, лимит ИИ-задач, аудит.
