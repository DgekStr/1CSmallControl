# Решения по ИИ-модулю (утверждено 11–12.11.2026)

Документ фиксирует ответы пользователя на вопросы ревью. При конфликте с `README.md` — приоритет здесь.

## 1. Утверждённые решения

| № | Вопрос | Решение |
|---|---|---|
| 1 | Где работает LLM | **Пока только облако с маскированием ПДн** (локальная модель — позже) |
| 2 | Как ИИ читает данные | **Гибрид**: SQL по копии для структуры + **HTTP-сервис 1С** для учётных данных |
| 3 | Свежесть песочницы | **Кнопка «Песочница ИИ»** у пользователя: живой срез базы, **не чаще 1 раза в сутки**; работа по срезу |
| 4 | Кому доступен ИИ | Любой пользователь с флагом ИИ **при наличии доступа к базе** (проверка обязательна) |
| 5 | Формат отчётов | **HTML в портале + PDF**, PDF формируется **на сервере (LibreOffice)** |
| 6 | Лимиты | **5 задач в день** на пользователя, **задача до 30 минут** |
| 7 | Ответственность | **Бухгалтер подтверждает/отклоняет каждую находку** |
| 8 | Детекторы | 8 проверок по [detectors.md](detectors.md): БП (6), НДС (1), ЗУП (1) |
| 8a | Сценарии для промтов | закрытие периода, сверка взаиморасчётов, НДС, зарплата (ЗУП) — к текущим четырём |
| 9 | Владелец детекторов | **Администратор портала** (текущий исполнитель) |
| 10 | «Тестирование и исправление» | ИИ **только находит и показывает**; исправляет человек в песочнице |
| 11 | Хранение отчётов | **30 дней**, затем автоудаление |

## 2. Механика «Песочница ИИ»

```text
Кабинет → [🤖 ИИ] → кнопка «Песочница ИИ»
        │
        ▼
Живой срез базы (копия ~1,8 ГБ, создание 5–15 мин)
        │  не чаще 1 раза в сутки
        ▼
Работа ИИ строго по срезу; на отчёте — дата и время среза
        │
        ▼
Блокировка на 3 часа; второй пользователь получает
«Песочница сейчас занята, попробуйте через 3 часа»
```

| Правило | Поведение |
|---|---|
| Срез чаще 1 раза в сутки | отказ «сегодняшний срез уже создан в HH:MM, используем его» |
| Нет доступа к базе | отказ «нет доступа к базе» (флаг ИИ не помогает) |
| Песочница занята | отказ с именем пользователя и временем до освобождения |
| Завершил задачу | блокировка снимается кнопкой «Завершить» |
| Прошло 3 часа | блокировка снимается таймером |

## 3. Что проверяет ИИ и что делает человек

| Этап | Кто |
|---|---|
| Создание среза | кнопка пользователя, контролирует портал |
| Проверки, поиск ошибок, сверки | **ИИ** (только чтение) |
| Подтверждение находки «верно / ложное» | **бухгалтер** |
| Исправление данных | **человек в песочнице или в 1С** |
| «Тестирование и исправление» | только человек, ИИ лишь показывает результат |
| Подготовка отчёта PDF | портал (LibreOffice) |

## 4. Лимиты инфраструктуры

| Ресурс | Значение |
|---|---|
| Срезов в сутки на пользователя | 1 |
| Песочниц одновременно | 1 |
| Удержание блокировки | 3 часа |
| Задач в день на пользователя | 5 |
| Длительность одной задачи | до 30 минут |
| Срок жизни отчёта | 30 дней |
| Размер песочницы | до 20 ГБ |

Свободно на момент утверждения: 26 ГБ (`/var/lib/pgpro`), 6,3 ГБ (`/`). Поэтому лимит срезов — 1 в сутки, старые песочницы удаляются перед созданием новой.

## 6. Итоговая оценка

| Параметр | Значение |
|---|---|
| Срок | 7–9 недель |
| Первый этап | правила + роль БД + место под песочницы |
