Решения по ИИ-модулю (утверждено 11–12.11.2026)

Документ фиксирует ответы пользователя на вопросы ревью. При конфликте с README.md — приоритет здесь.

1. Утверждённые решения

№ВопросРешение
1Где работает LLMПока только облако с маскированием ПДн (локальная модель — позже)
2Как ИИ читает данныеГибрид: SQL по копии для структуры + HTTP-сервис 1С для учётных данных
3Свежесть песочницыКнопка «Песочница ИИ» у пользователя: живой срез базы, не чаще 1 раза в сутки; работа по срезу
4Кому доступен ИИЛюбой пользователь с флагом ИИ при наличии доступа к базе (проверка обязательна)
5Формат отчётовHTML в портале + PDF, PDF формируется на сервере (LibreOffice)
6Лимиты5 задач в день на пользователя, задача до 30 минут
7ОтветственностьБухгалтер подтверждает/отклоняет каждую находку
8Детекторы8 проверок по detectors.md: БП (6), НДС (1), ЗУП (1)
8aСценарии для промтовзакрытие периода, сверка взаиморасчётов, НДС, зарплата (ЗУП) — к текущим четырём
9Владелец детекторовАдминистратор портала (текущий исполнитель)
10«Тестирование и исправление»ИИ только находит и показывает; исправляет человек в песочнице
11Хранение отчётов30 дней, затем автоудаление

2. Механика «Песочница ИИ»

Кабинет → [🤖 ИИ] → кнопка «Песочница ИИ»
        │
        ▼
Живой срез базы (копия ~1,8 ГБ, создание 5–15 мин)
        │  не чаще 1 раза в сутки
        ▼
Работа ИИ строго по срезу; на отчёте — дата и время среза
        │
        ▼
Блокировка на 3 часа; второй пользователь получает
«Песочница сейчас занята, попробуйте через 3 часа»
ПравилоПоведение
Срез чаще 1 раза в суткиотказ «сегодняшний срез уже создан в HH:MM, используем его»
Нет доступа к базеотказ «нет доступа к базе» (флаг ИИ не помогает)
Песочница занятаотказ с именем пользователя и временем до освобождения
Завершил задачублокировка снимается кнопкой «Завершить»
Прошло 3 часаблокировка снимается таймером

3. Что проверяет ИИ и что делает человек

ЭтапКто

«Тестирование и исправление»только человек, ИИ лишь показывает результат
Подготовка отчёта PDFпортал (LibreOffice)

4. Лимиты инфраструктуры

РесурсЗначение
Срезов в сутки на пользователя1
Песочниц одновременно1
Удержание блокировки3 часа
Задач в день на пользователя5
Длительность одной задачидо 30 минут
Срок жизни отчёта30 дней
Размер песочницыдо 20 ГБ

Свободно на момент утверждения: 26 ГБ (/var/lib/pgpro), 6,3 ГБ (/). Поэтому лимит срезов — 1 в сутки, старые песочницы удаляются перед созданием новой.
