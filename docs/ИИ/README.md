# ИИ-модуль портала 1C Small Control — правила работы

> **Документ обновлён 12.11.2026 (v1.1).** Актуальные решения — в [decisions.md](decisions.md):
> только облако с маскированием ПДн · 1 срез в сутки · PDF на сервере · 5 задач/день ·
> отчёты 30 дней · проверка доступа к базе обязательна · детекторы — [detectors.md](detectors.md).

Версия документа: **1.1** · Дата: 12.11.2026 · Статус: проект (реализация не начата)

## 1. Назначение

ИИ-модуль — встроенный в портал помощник для бухгалтеров и администраторов, который выполняет
проверки баз 1С, ищет ошибки в данных, потерянные документы и типовые ошибки учёта.

**Главный принцип: ИИ никогда не работает с живой базой. Только с песочницей — её копией.**

## 2. Железные правила (не нарушаются ни при каких условиях)

| № | Правило | Следствие |
|---|---|---|
| 1 | ИИ работает **только в песочнице** | живая база не доступна ИИ ни на чтение, ни на запись |
| 2 | Песочница — **копия одной базы**, созданная штатным `1c-sandbox` | в песочницу попадают только данные этой базы |
| 3 | ИИ работает **только с одной песочницей одновременно** | вторая сессия получает ответ «песочница занята» |
| 4 | В песочнице разрешено **только чтение** (роль `SELECT`) | никакие изменения данных невозможны |
| 5 | Каждый ответ ИИ **помечен датой среза** данных | «данные на 11.11.2026 03:00, песочница sb_…» |
| 6 | Все вызовы ИИ попадают в **аудит портала** | кто, когда, какая база, какой запрос, что вернулось |
| 7 | Песочница живёт **не дольше 7 дней** | автоудаление, освобождение места |
| 8 | Персональные данные **маскируются** перед отправкой в модель | ФИО, ИНН, СНИЛС заменяются метками; суммы сохраняются (без них отчёт бесполезен) |

## 3. Эксклюзивность песочницы

Одновременно с ИИ может работать **только одна песочница и один пользователь**.

```text
Пользователь А запускает задачу ИИ
        │
        ▼
Песочница sb_dgekdb_11110300 закреплена за А (status = busy, ttl = 3 часа)
        │
Пользователь Б пытается запустить ИИ
        ▼
Ответ: «Песочница сейчас занята пользователем А (задача «поиск ошибок»,
       начата 11.11.2026 10:30). Попробуйте через 3 часа.»
```

Правила блокировки:

| Ситуация | Поведение |
|---|---|
| Песочница свободна | создаётся/берётся свободная, ИИ запускается |
| Песочница занята другим пользователем | отказ с текстом «занята, попробуйте через 3 часа» |
| Песочница занята текущим пользователем | продолжается его диалог |
| Истекли 3 часа | блокировка снимается автоматически, песочница помечается `stale` |
| Пользователь нажал «Завершить» | блокировка снимается сразу |

## 3.1. Обязательное условие запуска — доступ к базе

Флаг ИИ сам по себе **не даёт права** проверить базу. Срез создаётся только по базе,
где у пользователя есть строка в `access`. Иначе — отказ «нет доступа к базе».

| Ситуация | Поведение |
|---|---|
| Флаг ИИ есть, доступ к базе есть | срез создаётся, задача выполняется |
| Флаг ИИ есть, доступа к базе нет | отказ, запись в аудит |
| Флага нет | кнопка ИИ в кабинете не отображается |

## 3.2. Срез данных — «Песочница ИИ»

| Параметр | Значение |
|---|---|
| Кнопка | «Песочница ИИ» в кабинете (шапка, кнопка 🤖) |
| Частота | **не чаще 1 раза в сутки** на пользователя |
| Повторный запуск | «сегодняшний срез создан в HH:MM, используем его» |
| Время создания | 5–15 минут (копия ~1,8 ГБ) |
| Удержание | блокировка 3 часа, затем освобождается |
| Хранение песочницы | автоудаление, чтобы не забить диск |

## 4. Включение функции

### 4.1. Админка → Пользователи

Функция включается **только администратором**, для конкретного пользователя:

```text
Админка → Пользователи → [пользователь] → Настройки → «ИИ-помощник»: вкл/выкл
```

В **списке клиентов** рядом с именем пользователя отображается **значок ИИ**:

| Отображение | Значение |
|---|---|
| 🟢 значок ИИ | функция включена и доступна |
| ⚪ значок перечёркнут | функция выключена |
| 🟡 значок с точкой | песочница занята / задача выполняется |

### 4.2. Кабинет клиента

У пользователя с включённым ИИ **после создания песочницы** в кабинете появляется
**кнопка-иконка ИИ** (в стиле остальных кнопок шапки, рядом с конвертом обратной связи).

```text
Кабинет → шапка → [✉ обратная связь] [🤖 ИИ] [⚙ настройки] [⎋ выход]
                     │
                     ▼
        Диалог ИИ: поле задачи, список заданий, отчёты
```

| Элемент | Что делает |
|---|---|
| Поле задачи | свободный текст: «найди ошибки в реализации», «почему не закрывается месяц» |
| Список заданий | готовые сценарии: проверка базы, поиск ошибок, потерянные документы, ошибки бухгалтера |
| Отчёт | результат с таблицей, ссылкой на песочницу и датой среза |
| Карточка занятости | кто занимает песочницу и до какого времени |
| Кнопка «Завершить» | снимает блокировку, освобождает песочницу |

Если песочницы нет — кнопка ИИ **неактивна** с подсказкой «Сначала создайте песочницу».

## 5. Что ИИ делает и чего не делает

| Делает | Не делает |
|---|---|
| Проверяет структуру и данные копии | не меняет данные в живой базе |
| Ищет дубли, пустые реквизиты, расхождения | не проводит документы и не исправляет проводки |
| Находит документы без движений и движения без документов | не удаляет документы |
| Объясняет ошибку бухгалтера и показывает первичные данные | не принимает решений за бухгалтера |
| Запускает «Тестирование и исправление» **в копии** | не запускает проверки на проде |
| Формирует отчёт с указанием источника | не выдаёт цифры без ссылки на запрос |
| Показывает находки для проверки бухгалтеру | не исправляет данные и не проводит документы |
| Запускает «Тестирование и исправление» | — |

## 6. Техническая схема

```text
Живая база dgek-db
      │  ночью / по запросу (1c-sandbox create)
      ▼
Песочница sb_dgekdb_MMDDHHMM   →  PostgreSQL (роль SELECT)
      │
      ▼
MCP-сервер (Python, отдельный сервис)
      │  инструменты: check_structure, find_errors, find_missing_docs, explain_ledger
      ▼
LLM (локальная модель или шлюз с маскированием ПДн)
      │
      ▼
Кабинет портала: диалог + отчёт + аудит
```

## 7. Ограничения ресурсов

| Ресурс | Лимит |
|---|---|
| Песочниц одновременно | 1 |
| Время удержания песочницы | 3 часа после запуска задачи, максимум 7 дней жизни |
| Размер песочницы | до 20 ГБ (иначе создание отклоняется) |
| `statement_timeout` для ИИ-запросов | 30 секунд |
| Строк в одном ответе | 10 000 |
| Задач в день на пользователя | **5** |
| Длительность одной задачи | **до 30 минут** |
| Формат отчёта | HTML в портале + **PDF на сервере (LibreOffice)** |
| Хранение отчётов | **30 дней**, затем автоудаление |

## 8. Аудит

Каждое действие пишется в `audit`:

```text
action = 'ai_task'
actor  = логин пользователя
details = "<тип задачи> | песочница <имя> | база <slug> | строк <n> | <результат>"
```

Администратор видит журнал: **Админка → Журнал заданий сервера → ИИ-задачи**.
