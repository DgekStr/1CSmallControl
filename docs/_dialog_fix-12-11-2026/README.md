# Слепок диалога 12.11.2026 — «1C Small Control»

Каталог содержит восстановленный по ходу сессии журнал работ и переписки
по инциденту с кластером 1С, базами и порталом **12 ноября 2026 года**.

| Файл | Содержание |
|---|---|
| `README.md` | этот индекс |
| `dialog.md` | хронология диалога: запросы пользователя → что сделано → результат |
| `actions-log.md` | технический журнал: команды, скрипты, проверки, показатели |
| `state.md` | состояние системы на момент закрытия слепка (версии, базы, заделы) |
| `prompt-cluster-stability.md` | копия md-промпта для ИИ (разбор нестабильности) |

> Слепок реконструирован из контекста сессии. Формулировки пользователя приведены
> близко к оригиналу, ответы — сжато; все технические факты (команды, выводы, статусы)
> взяты из выполненных в сессии действий.
