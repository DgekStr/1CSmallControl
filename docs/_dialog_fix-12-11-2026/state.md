## Заделы / что осталось

1. **Пуш 4 коммитов** — по команде «пуш можно» (или выпуск 2.1.1).
2. **Фантом `goncharov`** — удалить через Windows-консоль `1CV8 Servers` (свой админ ИБ).
3. **`montes_buh`** — 3,1 ГБ без публикации: удалить или опубликовать (по решению пользователя).
4. **Пароль `Бухгалтера` `000`** — для боевой работы сменить.
5. **Полнотекстовый поиск** — после импортов следить за `1Cv8FTxt`; при перегрузке отключать.
6. **`docs/prompt-cluster-stability.md`** — передать ИИ для разбора нестабильности.

## Известные ограничения

- Правка реестра `1CV8Clst*.lst` вручную — только с бэкапом; дважды ломала кластер.
- `1c-verify-base` меняет пароль всегда; `1c-heal-bases` вызывает её только при сбое проверки.
- Шлюз `/WEB/` резолвит базу по `slug | ib_name | db_name` — база обязана быть в `portal.db`.
