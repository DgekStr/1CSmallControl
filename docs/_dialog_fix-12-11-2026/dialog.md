## Ключевые уроки дня

1. Правка реестра 1С руками — недопустима без необходимости (счётчики ломаются, кластер падает).
2. Автовосстановление должно быть консервативным: один сбой RAC ≠ авария; rphost — обязательный признак.
3. «Восстановление паролей» нельзя делать вслепую: сначала проверка, потом лечение.
4. У каждой базы должны совпадать имена: инфобаза = публикация; `db_name` — отдельное поле.
5. После `.dt` неизбежна переиндексация: контролировать диск и полнотекстовый поиск.
