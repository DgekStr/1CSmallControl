## Кратко о проблеме

- Первый вход в базу после простоя — 3–5 минут, повторный — быстро.
- Портал и страница входа открываются за 2 с; зависает именно «Войти».
- PostgreSQL не при чём (сессии idle, блокировок 0); RAM/диск свободны.
- HASP: `Loaded 0 licenses`, `error.log` 42 МБ растёт, ключ HASP HL 990364755 «без конфигурации».
- `rphost` постоянно ~190% CPU (фоновые задания/индексация).
