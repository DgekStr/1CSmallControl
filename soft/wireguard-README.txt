Установщики WireGuard для клиентов портала 1С
=============================================

Зачем здесь эти файлы
---------------------
Официальный сайт wireguard.com в России недоступен (блокировка Роскомнадзора),
поэтому установщики лежат на нашем сервере и отдаются из личного кабинета клиента.

Файлы
-----
wireguard-amd64-1.1.1.msi   WireGuard для Windows, 64-бит (версия 1.1.1), 3,1 МБ
wireguard-x86-1.1.1.msi     WireGuard для Windows, 32-бит (версия 1.1.1), 3,1 МБ

Как отдаются
------------
Ссылки в кабинете клиента появляются только когда администратор включил у клиента VPN
и загрузил конфигурацию. Скачивание доступно после входа в портал:
    /download/wireguard/wireguard-amd64-1.1.1.msi
    /download/wireguard/wireguard-x86-1.1.1.msi
Каждое скачивание пишется в журнал портала (vpn_soft).

Что сказать клиенту
-------------------
1. Установить WireGuard (64-бит на современные компьютеры, 32-бит — на старые).
2. «Импорт туннеля из файла» → выбрать конфигурацию из кабинета.
3. Включить туннель. В локальной сети офиса VPN не нужен.

Телефон: приложение WireGuard из App Store / Google Play, конфигурация добавляется
сканированием QR-кода (QR выдаёт администратор).

Обновление файлов
-----------------
1. Скачать новые MSI с зеркала (например, из кэша или с github.com/WireGuard/wireguard-windows/releases).
2. Положить в /opt/1c-portal/soft/wireguard/ с правами 640 root:www-data.
3. Обновить имена файлов и подписи в app.py (WIREGUARD_FILES) и в шаблоне templates/portal.html.

Проверка
--------
curl -I -b cookies.txt https://1c.dgek.ru/download/wireguard/wireguard-amd64-1.1.1.msi
Ожидаем: 200, Content-Disposition: attachment
